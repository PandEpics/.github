## Pandemic Epistemics: If we had the models, would we have the knowledge?

There was a flurry of research during the pandemic, with many papers attempting to characterize epidemiological features and make predictions about future dynamics. Each new model built on the information we had before. But what if we had our current knowledge - would we have done anything differently?

In this organization, we will perform replications of pandemic studies using the data available at different points in the pandemic to see what would happen.

- Did the estimates of the epidemiological parameters change?
- Did the predictions pan out?
- Did data collection issues translate into flawed conclusions in the models?
- For decisions made based on studies, could we have made those decisions earlier if we had done the analysis earlier?

The ultimate goal is to have an idea of which modelling efforts were most useful so that we're better prepared for the next pandemic.
